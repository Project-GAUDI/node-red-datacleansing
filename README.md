## 概要

node-red-datacleansingは、下記処理を行うNode-REDのカスタムノードです。

## 機能

入力データの抽出・変換を行う機能。  
以下のノードを含む。

* Get Format ID GAUDI 標準メッセージの先頭レコードの RecordHeader の先頭カラムから  
GAUDI標準CSVファイル命名規則(※)のフォーマットID相当部分を抽出する。  
※GAUDI標準CSVファイル命名規約:  
&emsp; 「送信先No（英数字3桁）_フォーマットNo（英数字3-4桁）_国コード（英数字2桁）  
&emsp; +会社コード（英数字2桁）+工場・棟コード（英数字3桁）+データ種別（英数字3桁）  
&emsp; +フリーエリア（英数字5桁）_タイムスタンプ等の可変データ.csv」の形式  
![get-format-numidber overview image](./docs/img/get-format-id_overview.drawio.png)

* Data Cleansing メッセージに付与されたフォーマット情報を元に入力データのクレンジング（フィルタリング／変換）を行う。  
![data-cleansing overview image](./docs/img/data-cleansing_overview.drawio.png)

各ノードを組み合わせて、  
入力データに対するフォーマット情報の付与とクレンジング処理を下記のようなシンプルなフローで実装可能。  
![flow image](./docs/img/flow_image.png)

### Get Format ID

#### 機能概要

GAUDI 標準メッセージの先頭レコードの RecordHeader の先頭カラムから  
GAUDI標準CSVファイル命名規則のフォーマットID相当部分を抽出する。

#### プロパティ

![get-format-id ui image](./docs/img/get-format-id-ui.png)

| プロパティ | Type                 | Required | Conditions      | Default              | Description                                                                                                             |
| ---------- | -------------------- | -------- | --------------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 名前       | textbox              |          |                 |                      | ノードの表示名を設定。                                                                                                  |
| 入力       | selectlist & textbox | 〇       | [GAUDI msg.]    | GAUDI msg. & payload | GAUDI標準メッセージ形式データを保持するmsgオブジェクト下の要素名を指定。                                                |
| 出力       | selectlist & textbox | 〇       | [metaKey, msg.] | metaKey & format     | フォーマットIDの設定先。<br>metaKey：メタキー（メッセージプロパティ）として設定<br>msg.：msg オブジェクト下の要素に設定 |

#### 使用例1

入力メッセージからフォーマットIDを抽出し、メッセージプロパティに出力する。

[フロー構成]

![get-format-id usecase1](./docs/img/get-format-id_usecase1.drawio.png)
  
[プロパティ]

| プロパティ | Value                |
| ---------- | -------------------- |
| 入力       | GAUDI msg. & payload |
| 出力       | metaKey & format     |

```json
{
  "payload": {
    "RecordList":[
      {
        "RecordHeader":["017_333_JP0110101000000_ES7_0110_202508071130.CSV","1"], 
        "RecordData":["1", "2", "3"]
      }
    ]
  }
}
```

[出力メッセージ]

```json
{
  "payload": {
    "RecordList":[
      {
        "RecordHeader":["017_333_JP0110101000000_ES7_0110_202508071130.CSV","1"], 
        "RecordData":["1", "2", "3"]
      }
    ]
  },
  "properties": {
    "PropertyList":[
      {
        "key":"format", 
        "value":"333"
      }
    ]
  }
}
```

##### ユーザ定義変換関数要求仕様

###### 引数1

変換対象入力データ。  
フォーマット情報の入力インデックス数が１の場合は単独データ、  
フォーマット情報の入力インデックス数が２以上の場合は配列データが入力される。  

###### 引数2

変換オプションデータ。  
フォーマット情報の Options で指定された変換オプションデータが渡される。  
Options に指定されているデータの件数が１の場合は単独データ、２以上の場合は配列データで入力される。  

###### 戻り値

変換結果を返す。

###### 関数イメージ

```python
import math
# 入力値（リスト内の数値）を指定した options の桁数（小数点以下）に切り捨てる
def floor_data(input, options):
    def process_value(value):
        retValue = math.floor(float(value) * 10 ** options) / (10 ** options)
        if retValue < 0:
            retValue = retValue + (10 ** -options)
        return round(retValue, options)

    return [process_value(value) for value in input]
```
